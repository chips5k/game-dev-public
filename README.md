# Game Dev Public

A collection of web and native game engine experiments built over 2016–2018.

## Projects

### [2D Canvas Engine](2d-canvas-engine) (2016)
TypeScript game engine running on HTML5 Canvas. Rigid body physics, vector math, visitor pattern for game state traversal, and a playable Pong demo.

### [Physics Prototypes](prototypes) (2016)
Early TypeScript physics engine prototypes exploring rigid body dynamics, collision detection, and edge correction.

### [Transfer Game](transfer-game) (2017)
Orbital mechanics simulation in vanilla JavaScript. Explore Hohmann transfer trajectories and gravitational interactions.

### [TMX Map Loader](tmx-map-loader) (2017)
JavaScript TMX tilemap parser and renderer. Loads Tiled `.tmx` JSON export, renders tile layers on Canvas, and handles basic rigid body collision.

### [OpenGL Renderer](opengl-renderer) (2018)
C++ OpenGL renderer with camera controls, texture loading via stb_image, and GLSL shaders. CMake build using system-installed GLFW and GLM.
